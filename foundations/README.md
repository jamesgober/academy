# Foundations

The vocabulary of programming, taught from zero. No language required. Read
this in order — each page assumes the one before it.

By the end you will understand what a program is, what data is, how a program
makes decisions and repeats work, and what the words *variable*, *function*,
*type*, and *class* actually mean. After this, any language course will make
sense.
