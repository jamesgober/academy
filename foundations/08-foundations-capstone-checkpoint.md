# Foundations Capstone Checkpoint

> Validate that you can think like a programmer before entering deeper language tracks.

**You will practice:**
- variables and types
- functions
- decision logic
- loops
- objects and classes

**Before this page, you should know:**
- [Classes and Inheritance Basics](./07-classes-and-inheritance-basics.md)

---

## Capstone brief

Design a tiny game-simulation module with the following:

1. Define a class `Car` with at least:
   - `color`
   - `max_speed`
   - `health`
2. Add one subclass, such as `PoliceCar`, with an extra behavior.
3. Create at least two objects from your classes.
4. Write one function that updates car state each tick.
5. Use decisions (`if/elif/else`) for damage or speed rules.
6. Use a loop to simulate multiple ticks.

## Self-check rubric

- Can you explain class vs object in one clear sentence?
- Are variable names meaningful and type-aware?
- Are functions focused and reusable?
- Is your control flow readable?
- Does your loop terminate correctly?

> [!IMPORTANT]
> If any rubric item is unclear, revisit the relevant lesson before moving on.

## Ready-for-next-track checklist

- You can read and write basic logic without guessing.
- You can trace state changes through loops and conditions.
- You can model a simple real-world/game concept with classes and objects.
