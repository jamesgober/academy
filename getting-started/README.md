# Getting Started

Set up your machine to write and run code. Pick your operating system below and
follow it start to finish — you'll install a code editor, a language toolchain,
and create an organized place to keep your projects.

Each platform has its own page so the screenshots and commands match exactly
what you'll see. No "on Mac do this, on Windows do that" mid-sentence confusion.
