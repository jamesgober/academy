# Terminal on Linux

> The terminal is a first-class part of Linux development. You will use it often.

**You will learn:**
- How to open a terminal session
- The minimal commands used across Academy
- How to avoid common path mistakes

---

## Open Terminal

- Use your desktop launcher and search for `Terminal`.
- Or use your desktop shortcut if configured (often Ctrl + Alt + T).

## First commands to know

```bash
pwd
ls
cd ~/Dev
```

- `pwd` prints your current folder.
- `ls` lists files and folders.
- `cd` moves to another folder.

## Running tool checks

```bash
cargo --version
rustc --version
```

If commands are not found after installation, open a new terminal session.

> [!WARNING]
> Command behavior can differ slightly by shell and distribution. If a course
> uses `bash` commands, run them in a bash-compatible shell.
