# Terminal Basics

> Learn the minimum terminal workflow you need for every course in Academy.

**You will learn:**
- What a terminal is and why course pages use it
- How to run commands and read command output
- How to choose the correct shell for your operating system

---

## What a terminal is

A terminal is a text interface where you run commands directly on your machine.
Many programming tools are command-line tools, so knowing a few terminal basics
removes friction everywhere else.

> [!NOTE]
> You do not need to memorize dozens of commands. You need a reliable starter set.

## The command model

Most commands follow this pattern:

```text
command option argument
```

Example:

```text
cargo --version
```

- `cargo` is the command.
- `--version` is an option (a modifier).
- The output line tells you the installed Cargo version.

## Your shell by platform

- Windows: use [PowerShell](./terminal-windows-powershell.md)
- macOS: use [Terminal on macOS](./terminal-macos.md)
- Linux: use [Terminal on Linux](./terminal-linux.md)

> [!TIP]
> Stick to one shell while learning. Consistency makes command behavior predictable.

## Core habits that prevent common mistakes

- Read the command before pressing Enter.
- Run one command at a time when learning.
- Copy errors exactly when searching for fixes.
- Reopen your terminal after installing tools that update `PATH`.
