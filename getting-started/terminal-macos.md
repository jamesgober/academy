# Terminal on macOS

> Use the built-in Terminal app for all command-based steps in Academy.

**You will learn:**
- How to open Terminal on macOS
- How to run basic commands
- How to verify tools correctly

---

## Open Terminal

- Press Cmd + Space, type `Terminal`, then press Enter.

## First commands to know

```bash
pwd
ls
cd ~/Dev
```

- `pwd` prints your current folder.
- `ls` lists files and folders.
- `cd` moves to another folder.

## Running tool checks

Course pages often ask for version checks:

```bash
cargo --version
rustc --version
```

If a command fails right after installation, close Terminal and open it again.

> [!TIP]
> Keep your learning projects under `~/Dev` so every guide and screenshot maps cleanly.
