# VS Code Basics

> Set up a clean VS Code workflow you can use across every language track.

**You will learn:**
- How to open projects the right way
- The minimum editor features to use daily
- Which Rust extensions to install after Rust setup

---

## Open folders, not single files

In VS Code, open your project folder so search, terminal, and extensions all
work with full context.

- Menu: **File -> Open Folder...**
- Terminal shortcut flow: `cd` into your project, then run `code .`

> [!TIP]
> `code .` means "open the current folder in VS Code." It is the fastest start.

## Essential workflow

- Use the integrated terminal for course commands.
- Use global search to find symbols quickly.
- Keep Explorer, Editor, and Terminal visible when learning.

## Recommended Rust extensions

Install these after you complete Rust setup:

- `rust-lang.rust-analyzer`
- `vadimcn.vscode-lldb`
- `tamasfe.even-better-toml`

Optional quality-of-life:

- `usernamehw.errorlens`

> [!NOTE]
> Extension recommendations are intentionally short. Add more only when a clear
> problem appears.
