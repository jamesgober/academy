# Loops and Iteration Patterns

## Common loops

- `for`
- `while`
- range-based `for`

```cpp
for (int i = 0; i < 5; ++i) {
}
```

`i` is a naming convention only; use any clear variable name.

## Range loop

```cpp
for (const auto& item : items) {
}
```
