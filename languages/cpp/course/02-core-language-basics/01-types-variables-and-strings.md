# Types, Variables, and Strings

## Core types

- `int`, `long long`
- `double`, `float`
- `bool`
- `char`
- `std::string`

## Range guidance

Use fixed-width integers when range matters:
- `std::int32_t`
- `std::int64_t`

## String note

C++ supports `std::string` directly (unlike C's raw char array model).
