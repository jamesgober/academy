# Your First C++ Program

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++" << std::endl;
    return 0;
}
```

## Line-by-line

- `#include <iostream>` gives stream I/O tools
- `int main()` is program entry point
- `std::cout` prints output
- `return 0` indicates successful exit
