# Core Syntax Cheat Sheet

Quick lookup for C fundamentals.

## Variable declarations

```c
int count = 0;
char grade = 'A';
float price = 3.5f;
```

## Function pattern

```c
int add(int a, int b) {
    return a + b;
}
```

## Conditionals

```c
if (score >= 50) {
    /* pass */
} else {
    /* fail */
}
```

## Loops

```c
for (int i = 0; i < 10; i++) {
    /* work */
}

while (count < 10) {
    count++;
}
```

## Common beginner reminder

- `=` assigns
- `==` compares
