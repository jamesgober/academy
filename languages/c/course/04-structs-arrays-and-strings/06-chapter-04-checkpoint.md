# Chapter 04 Checkpoint

> Confirm you can model structured data and handle strings safely.

## Must-be-able checklist

- Define and use a struct.
- Define and iterate through an array.
- Explain C string null terminators.
- Apply bounded string-write patterns.
- Identify at least one overflow risk in a bad snippet.

## Practice task

Build a small "garage records" model:
- a `struct CarRecord` with name and numeric fields
- an array of records
- one update function that uses safe string handling

## Reviewer checklist

- Are array bounds respected?
- Is string capacity handled explicitly?
- Are writes to buffers bounded and checked?
