# Chapter 02 Checkpoint

> Confirm you can read and write small C programs before moving into pointers.

## Must-be-able checklist

- Declare variables with explicit types.
- Write and call a simple function.
- Use `if` and `else` clearly.
- Use `for` or `while` for repetition.
- Explain the difference between assignment and comparison.

## Practice task

Build a small "garage queue" program that:
- stores a car count
- uses a function to adjust a value
- prints status with a conditional
- loops through a few entries

## Reviewer checklist

- Are types explicit and appropriate?
- Are the conditionals readable?
- Does the loop have an obvious stopping rule?
