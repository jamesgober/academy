# What Source Files and Executables Are

> C becomes much easier once you stop treating files and build outputs as mysterious blobs.

**You will learn:**
- What source files are
- What executables are
- Why the compiler output is not the same thing as your source code

**Before this page, you should know:** [Compiling and Running Step by Step](./03-compiling-and-running-step-by-step.md)

---

## Source file

A source file is the human-readable code you write, such as `main.c`.

## Executable

An executable is the compiled program your operating system runs.

## Why the difference matters

When something goes wrong, ask which layer is affected:
- source code
- compile step
- executable behavior

That question is basic, but it saves a lot of confusion.

---

## Recap

- Source files are written by humans.
- Executables are built by the compiler.
- Debugging gets easier when you separate the layers mentally.

## Try it yourself

List the files in your project folder before and after compiling, then identify which file you wrote and which file the compiler produced.
