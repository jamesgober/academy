# Go

Go is a practical, beginner-friendly language for building simple, reliable
software. This track teaches Go in a slower, clearer sequence: setup, first
programs, packages, modules, testing, concurrency, and project structure.

## Testing and quality expectations

This track follows [Language Testing and Quality Standards](../testing-and-quality-standards.md).
