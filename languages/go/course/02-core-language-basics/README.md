# Chapter 02 — Core Language Basics

Learn the beginner mental model for writing Go: variables, types, functions,
conditions, loops, and how Go reads top to bottom without a lot of ceremony.

> [!IMPORTANT]
> This chapter moves slowly on purpose. A learner should leave this chapter able
> to read ordinary Go code without guessing what each line is doing.
