# Chapter 02 Checkpoint

> Confirm you can read and write small Go programs before moving deeper.

## Must-be-able checklist

- Create variables with clear types and values.
- Write and call a simple function.
- Use `if` and `else` to choose behavior.
- Use `for` to repeat work.
- Explain the difference between arrays, slices, and maps.

## Practice task

Build a small "garage check-in" program:
- store a driver name
- store a slice of car names
- store a map of car name to readiness status
- print a message for each car

## Expected output characteristics

Your solution should:
- print one readable line per car
- use a slice for repeated items
- use a map for status lookup

## Reviewer checklist

- Can the learner explain why each data structure was chosen?
- Is the loop readable without extra explanation?
- Do the variable names describe the values well?
