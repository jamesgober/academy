# Chapter 03 Checkpoint

> Confirm you can organize Go code without turning it into a maze.

## Must-be-able checklist

- Explain what a package is.
- Explain how exports work.
- Define a struct and method.
- Explain what an interface represents.
- Sketch a small multi-package project layout.

## Practice task

Design a small vehicle tracker project:
- one `main` package
- one reusable `garage` package
- one struct with methods
- one small interface for behavior boundary

## Reviewer checklist

- Is the package split obvious?
- Are exported names intentional?
- Is the interface small and justified?
