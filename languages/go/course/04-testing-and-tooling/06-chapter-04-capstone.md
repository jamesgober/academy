# Chapter 04 Capstone

> Prove you can test and verify a small Go package with a real workflow.

## Project brief

Build a small calculator or status-check package with:
- at least one exported function
- multiple tests
- at least one table-driven test
- a documented local quality workflow

## Expected outputs

Your project should show:
- readable `got` versus `want` test messages
- one edge case in the test set
- a clear `fmt`, `vet`, and `test` workflow

## Reviewer checklist

- Are failure messages useful?
- Are the test cases easy to scan?
- Is the quality workflow explicit and repeatable?
