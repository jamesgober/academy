# Chapter 01 : Getting Started

Install Go, run your first program, understand how Go files and packages fit
together, and build a clean daily command loop before the language gets more
complex.

> [!IMPORTANT]
> If terminal commands still feel unfamiliar, read the getting-started pages for
> your platform before pushing deeper into Go.

> [!NOTE]
> This chapter is intentionally concrete. The goal is to remove toolchain and
> project-layout confusion before you start learning more syntax.
