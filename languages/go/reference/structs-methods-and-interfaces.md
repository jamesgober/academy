# Structs, Methods, and Interfaces Cheat Sheet

> Fast lookup for Go's common custom-type building blocks.

## Quick definitions

- **struct**: grouped custom data
- **method**: function attached to a type
- **interface**: behavior contract described by methods

## Visibility reminder

- uppercase name: exported
- lowercase name: package-private

## Beginner reminders

- use structs to group related data
- use methods when behavior belongs to a type
- use small interfaces when they solve a real boundary problem
