# Commands and Tooling

## Core workflow actions

- run script
- run tests
- run lint checks
- run formatting checks
- run debugger session

## Browser-first execution workflow

1. open page with script
2. open Developer Tools Console
3. run and inspect code behavior
4. inspect Network and Sources panels for runtime details

## Tooling options

- browser developer tools (console, sources, network)
- editor-integrated debugger and breakpoints
- lint/format tools compatible with your project setup
- test frameworks for browser or runtime-based execution

Common frontend tool categories:
- bundlers/build tools
- test runners
- linting/formatting tools
- package managers

## Suggested local quality loop

1. lint
2. test
3. format
4. manual browser smoke-check

Use the specific commands provided by your chosen project tooling.
