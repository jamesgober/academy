# Conditionals and Loops Patterns

## if and else-if

```javascript
if (x > 10) {}
else if (x > 5) {}
else {}
```

## Ternary

```javascript
const label = isActive ? "active" : "inactive";
```

## switch

```javascript
switch (role) {
  case "admin":
    break;
  default:
    break;
}
```

## Loops

- `for`
- `while`
- `for...of`
- `for...in` (object keys, use with care)

Use descriptive loop variable names for non-trivial logic.
