# Chapter 04 Checkpoint

> Confirm asynchronous fluency before shipping full projects.

## You should be able to do all of this

- explain event loop output order
- chain and catch promise errors
- refactor chains to async/await
- call HTTP APIs with validation and timeout patterns

## Mini challenge

Create a script that:
- fetches two endpoints in parallel
- handles one failing request gracefully
- prints a combined summary

---

## Recap

- Async design is about reliability as much as speed.
- Error boundaries must be intentional.
- API code should fail loudly and clearly.

## Try it yourself

Add retry logic with a max-attempt counter to one API helper.
