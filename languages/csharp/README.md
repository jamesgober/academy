# C#

C# is a managed, strongly-typed language for building apps, APIs, tools, and
cloud services with the .NET platform.

This track is built for beginners who want professional outcomes: clear syntax,
solid OOP foundations, async workflows, testing discipline, and project
architecture that scales.

## Testing and quality expectations

This track follows [Language Testing and Quality Standards](../testing-and-quality-standards.md).
