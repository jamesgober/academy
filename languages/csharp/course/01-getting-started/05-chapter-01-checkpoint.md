# Chapter 01 Checkpoint

> Verify your toolchain and command workflow before moving into language fundamentals.

## You should be able to do all of this

- Install and verify .NET SDK
- Create a console project with `dotnet new`
- Build and run with confidence
- Read and fix basic compiler errors

## Self-check questions

1. What is the difference between `dotnet build` and `dotnet run`?
2. Why should you fix the first compiler error first?
3. Which command shows installed SDK versions?

---

## Recap

- Environment setup quality affects every future lesson.
- A predictable command loop saves debugging time.
- Diagnostic IDs help you search and solve issues faster.

## Try it yourself

Create a new project named `checkpoint-one`, run it, then intentionally add one typo and fix it.
