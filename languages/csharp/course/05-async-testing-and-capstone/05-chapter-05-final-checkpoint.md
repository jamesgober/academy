# Chapter 05 Final Checkpoint

> This checkpoint verifies you can move from beginner syntax to engineer-level workflow.

## You should be able to do all of this

- Write async methods without blocking patterns
- Build and run a test suite with xUnit
- Debug failures with a repeatable triage process
- Deliver a small project with clear architecture

## Final reflection prompts

1. Which design choices in your capstone made testing easier?
2. Where did async improve responsiveness or structure?
3. Which warning/error patterns were most common for you?

---

## Recap

- Engineering quality is process plus code.
- Tests, logging, and architecture notes improve maintainability.
- You now have a solid C# baseline for larger projects.

Write a one-page retrospective for your capstone: what worked, what broke, what you would improve.
