# GitHub Quick Reference

> Fast command and workflow lookup for daily use.

## Core Git loop

```bash
git status
git add .
git commit -m "type: intent"
git push
```

## Branch loop

```bash
git checkout -b feature/my-work
git push -u origin feature/my-work
```

## Pull latest main

```bash
git checkout main
git pull
```

## Create and push tag

```bash
git tag v0.5.0
git push origin v0.5.0
```

## Common files in healthy repos

- `README.md`
- `LICENSE`
- `CHANGELOG.md`
- `CONTRIBUTING.md`
- `.github/` templates and workflows
