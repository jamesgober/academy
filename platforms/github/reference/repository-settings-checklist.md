# Repository Settings Checklist

> Apply these settings early to avoid preventable project-management problems.

## Core settings

- Add clear description and topics.
- Set default branch (`main` is common).
- Enable branch protection for shared repositories.
- Require pull-request review before merge (for team repos).
- Enable Dependabot alerts and updates.

## Collaboration settings

- Add issue templates.
- Add pull-request template.
- Configure labels and milestones.
- Enable Discussions when community Q&A is expected.

## Security settings

- Enable secret scanning (where available).
- Enable two-factor authentication requirements for orgs.
- Restrict force pushes on protected branches.

> [!WARNING]
> Disabling branch protection in active team repos increases risk of accidental
> breakage on default branch.
