# README Structure Guide

> A strong README helps users understand your project in under two minutes.

## Recommended layout

1. Project name and one-line value statement
2. What it does
3. Quick start
4. Installation
5. Usage examples
6. Configuration
7. Contributing
8. License

## Minimal starter template

```markdown
# Project Name

One-line summary.

## Quick Start

## Installation

## Usage

## Contributing

## License
```

> [!TIP]
> Show at least one runnable example. Readers trust projects they can verify quickly.

## Common README mistakes

- Huge walls of text before any usage example
- Missing install instructions
- No explanation of project scope
- No license statement
