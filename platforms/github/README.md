# GitHub Masterclass

> A complete beginner-friendly path from "What is GitHub?" to running real,
> collaborative projects with clean standards.

## What this track is

This track teaches GitHub as a practical workflow platform: repositories,
issues, pull requests, reviews, documentation, community features, and delivery
features like Pages and Actions.

You will learn not just what buttons to click, but why teams use these tools.

## Track facts

| Item | Details |
|------|---------|
| Platform | GitHub |
| Company | GitHub, Inc. (Microsoft subsidiary) |
| Public launch | 2008 |
| Official website | <https://github.com> |
| Official docs | <https://docs.github.com> |
| Status page | <https://www.githubstatus.com> |

> [!IMPORTANT]
> GitHub uses Git, but GitHub is not the same thing as Git.
> Git is the version-control engine. GitHub is the hosted collaboration platform.

## Course and reference

- [Course](./course/) — structured lessons in order.
- [Reference](./reference/) — quick lookup pages for licenses, repository
  settings, README structure, and collaboration operations.

## Who this is for

- Absolute beginners who have never pushed code before.
- Solo developers who want professional project hygiene.
- Teams onboarding new contributors.
