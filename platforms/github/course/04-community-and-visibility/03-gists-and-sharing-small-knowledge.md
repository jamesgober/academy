# Gists and Sharing Small Knowledge

> A gist is a lightweight Git repository for short code snippets, notes, or examples.

**You will learn:**
- What a gist is
- When to use a gist vs a full repository
- How to share snippets safely

**Before this page, you should know:** [Discussions and Communication Channels](./02-discussions-and-communication-channels.md)

---

## What a gist is

A gist is ideal for:
- small examples
- quick scripts
- reusable snippets
- short reference notes

## When not to use gists

Do not use a gist when you need:
- project issue tracking
- structured releases
- team-level review workflows

In those cases, use a full repository.

## Security reminder

> [!WARNING]
> Never put secrets or private keys in gists. Public gists are visible to everyone.

## Good gist habits

- Give each gist a clear title.
- Add short usage context at top.
- Update or delete outdated snippets.

---

## Recap

- Gists are for small, focused sharing.
- Repositories are for full projects and collaboration.
- Public gist content should be treated as public forever.

## Try it yourself

Create a gist containing a reusable command cheat sheet and a one-line context
note.
