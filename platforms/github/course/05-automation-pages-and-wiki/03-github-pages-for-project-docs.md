# GitHub Pages for Project Docs

> GitHub Pages hosts static sites directly from your repository.

**You will learn:**
- What GitHub Pages is for
- How to publish docs site from a repository
- How to keep docs deployment stable

**Before this page, you should know:** [Setting Up a Basic CI Workflow](./02-setting-up-a-basic-ci-workflow.md)

---

## Common Pages use cases

- project documentation
- changelog/roadmap portal
- lightweight personal or team site

## Setup basics

1. Add docs content (`docs/` or dedicated branch).
2. Enable Pages in repository settings.
3. Choose source branch/folder.
4. Verify site URL after deployment.

> [!TIP]
> Keep docs content versioned in Git so historical updates are traceable.

---

## Recap

- Pages provides hosting for static content.
- Docs deployment should be tied to repository workflow.
- Versioned docs improve reliability and accountability.

## Try it yourself

Publish a minimal documentation landing page and link it in repository About settings.
