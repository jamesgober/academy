# What Is GitHub?

> GitHub is a website where people store code, track changes, and collaborate on software projects.

**You will learn:**
- What GitHub is in plain language
- How GitHub relates to Git
- Why beginners should learn GitHub early

**Before this page, you should know:** basic file and folder concepts.

---

## Explain it like you are new to all of this

Imagine you are writing a long school project with friends.

- You need one shared place for the project.
- You need to know who changed what and when.
- You need to discuss improvements before changing the final version.

GitHub is that place for code and technical documents.

<!-- SCREENSHOT: GitHub home page with navigation (Repositories, Issues, Pull Requests) highlighted -->

## Git vs GitHub

- **Git** is software that tracks file history on your computer.
- **GitHub** is an online platform built around Git that adds collaboration tools.

> [!IMPORTANT]
> People often say "push to GitHub" when they mean "use Git to send changes to a GitHub repository."

## What GitHub is used for

- Hosting repositories
- Reviewing code through pull requests
- Tracking work through issues
- Publishing project documentation
- Running automation with GitHub Actions

## Why this matters for beginners

Learning GitHub early teaches project hygiene:
- Small commits
- Clear history
- Better communication
- Reproducible collaboration

## Recap

- GitHub is a collaboration platform for Git repositories.
- Git tracks changes locally; GitHub helps teams work online.
- GitHub is not just for experts. It helps beginners stay organized.

## Try it yourself

Open <https://github.com/explore> and inspect three repositories. Identify where
Issues, Pull Requests, and README files are located.
