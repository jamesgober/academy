# Create Your First Repository

> A repository is the main container for your project code, docs, and history.

**You will learn:**
- How to create a repository on GitHub
- Which settings matter at creation time
- How to write useful About text and topics

**Before this page, you should know:**
- [Install Git and Create Your GitHub Account](./02-install-git-and-create-account.md)

---

## Create repository on GitHub

1. Click **New repository** from your GitHub dashboard.
2. Choose a short, clear name.
3. Add a one-sentence description.
4. Select **Public** or **Private**.
5. Initialize with `README.md`.
6. Add `.gitignore` template if available.
7. Choose a license if this will be shared publicly.

<!-- SCREENSHOT: New repository form with name, visibility, README, gitignore, and license options -->

## About section and topics

After creating the repo, fill:
- **About** description: one clear sentence about purpose.
- **Website**: project docs or homepage if available.
- **Topics**: short tags (for discoverability).

> [!TIP]
> Good topics help the right contributors find your project.

<!-- SCREENSHOT: Repository About section with description, website, and topics -->

## Public vs Private

- **Public**: anyone can view the repository.
- **Private**: only invited collaborators can view it.

> [!WARNING]
> Public repositories are visible to everyone, including commit history and issue discussions.

## Recap

- A repository is the core project container on GitHub.
- Metadata (description/topics/license) improves clarity and discoverability.
- Visibility choice (public/private) should match project goals.

## Try it yourself

Create a repository named `hello-github`, add a one-line description, and add
at least three relevant topics.
