# Screenshots

Illustrative screenshots for setup and tutorial pages.

Suggested naming: `<platform>-<topic>-<step>.png`
e.g. `windows-vscode-install.png`, `macos-vscode-applications.png`.

Pages reference these with a relative path and an HTML comment marking where a
shot belongs, e.g. `<!-- SCREENSHOT: ... -->`. Replace the comment with the
image tag once captured.
